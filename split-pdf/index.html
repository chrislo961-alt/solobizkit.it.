How to split a PDF

  1. Choose your PDF.Select the document you want to split or extract pages from.
  2. Enter page numbers.Use commas for separate pages and hyphens for ranges, for example 1-3, 6, 9-12.
  3. Extract and download.The selected pages are copied into one new PDF file.
Privacy: page extraction runs in your browser. This version accepts PDFs up to 100 MB.

Extract selected pages from a PDF

Use the free SoloBizKit Split PDF tool when you only need part of a larger document. Select a single page, several separate pages or complete page ranges and save those pages as a new PDF.

Split PDF by page ranges

Enter ranges such as 1-5 or combine ranges and individual pages such as 1-3, 7, 10-12. The selected pages are placed into the new PDF in page-number order.

Extract one page from a PDF

If you only need one page, enter that page number by itself. This is useful for pulling a certificate, invoice page, form, signature page or other single page out of a larger document without recreating the file.

Extract multiple non-consecutive PDF pages

You can also choose pages that are not next to each other. A selection such as 2, 5, 8-10 creates a new PDF containing those pages while leaving the original file unchanged.

Split reports, contracts and scanned documents

Page extraction can help when a report contains only a few pages you need to share, a contract has an appendix you want separately, or a scanned document includes pages that belong in another file.

Split versus delete PDF pages

Use Split PDF when you want to create a new document from the pages you select. If you instead want to keep most of the original document and remove unwanted pages, use Delete PDF Pages.

Free PDF splitting without an account

The current Split PDF tool is free to use and does not require a SoloBizKit account. Processing is designed to happen in your browser. Password-protected or damaged PDFs may need to be unlocked or repaired first.

Split PDF FAQ

Can I split a PDF online for free?

Yes. Choose a PDF, enter the pages you need and extract them into a new PDF without creating a SoloBizKit account.

Can I extract a single PDF page?

Yes. Enter only that page number in the page field.

Can I use several page ranges?

Yes. Separate pages and ranges with commas, for example 1-3, 6, 9-12.

Does splitting change the original PDF?

No. The selected pages are copied into a new PDF document.

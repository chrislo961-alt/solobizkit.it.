Connect guests to Wi-Fi with a QR code

A Wi-Fi QR code stores the network name, security type and password in a standardized text format. Compatible phones can scan the code and use those details to simplify joining the wireless network, which is useful when a password is long or difficult to type.

How to make a WiFi QR code

Enter the exact Wi-Fi network name (SSID), add the password, select the correct security type and generate the code. Scan-test the result with a phone before you print it or place it somewhere for visitors.

Wi-Fi QR codes for guests, offices and small businesses

A scannable Wi-Fi code can be useful in reception areas, meeting rooms, rental properties, cafés, salons, waiting rooms and guest spaces. If the Wi-Fi password changes, create and print a new QR code so visitors receive the current connection details.

Tips before printing your Wi-Fi QR code

  • Scan-test the code on more than one phone when possible.
  • Keep clear white space around the QR code.
  • Print it large enough to scan comfortably from the expected distance.
  • Do not publish a private network password where unintended visitors can scan it.

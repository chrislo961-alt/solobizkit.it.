How to crop a PDF

  1. Choose your PDF.Select the document whose page margins you want to trim.
  2. Set crop margins.Enter how many millimeters to remove from the top, bottom, left and right.

Tip: start with small values such as 5–10 mm. The tool blocks crop settings that would make a page invalid.

Crop PDF margins online for free

SoloBizKit Crop PDF is a focused browser tool for trimming page margins. It can reduce excess white space around scans, reports, exported documents and other PDFs without requiring desktop PDF software or an account.

Crop all PDF pages at once

Choose All pages to apply the same top, bottom, left and right crop margins throughout the document. This is useful when every page has consistent borders or unwanted whitespace.

Crop one PDF page

If only one page needs adjustment, choose One page and enter its page number. Other pages keep their existing visible page boundaries.

Crop PDF by millimeters

The tool accepts separate crop values for each edge in millimeters. Small values give you predictable margin trimming without changing the underlying page content.

PDF cropping is not secure redaction

Cropping changes what is normally visible on the page, but content outside the crop box can remain inside the PDF. Never rely on cropping to remove confidential text, personal data or other sensitive information.

Browser-based PDF cropping

The current tool is designed to modify the PDF page boxes in your browser and create a new file for download. Your original PDF remains unchanged.

Crop PDF FAQ

Can I crop a PDF for free?

Yes. The current Crop PDF tool is free and requires no SoloBizKit account.

Can I remove white margins from a PDF?

Yes. Enter the amount of whitespace you want to trim from each edge.

Can I crop every page?

Yes. The same crop values can be applied to all pages in one operation.

Does cropping permanently delete hidden content?

No. Cropping is not secure redaction and should not be used to remove sensitive information.

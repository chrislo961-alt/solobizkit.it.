Remove password protection from a PDF you are authorized to use

Use the free SoloBizKit Unlock PDF tool when you have the correct password and want a new copy that opens without a password prompt. The tool decrypts supported PDF security in the browser and leaves your original encrypted PDF unchanged.

Unlock AES-256 and RC4 protected PDFs

The current decryption engine supports AES-256 PDF encryption as well as legacy RC4 40-bit and 128-bit encryption. Some PDFs use AES-128 or other security handlers that are not supported by the current version.

Unlock PDF with the user or owner password

A PDF may have a password used to open the document and a separate owner password used for permissions. The current tool can use either valid password when the encryption type is supported.

This tool does not crack unknown PDF passwords

Unlock PDF is designed for legitimate password removal when you already know the correct password. It does not perform password guessing, brute-force attacks or attempts to bypass unknown credentials.

Why remove a PDF password?

Removing encryption can be useful when you own the document and need to process it with another PDF tool, archive an authorized unprotected copy, or avoid repeated password prompts in an approved workflow.

Browser-based PDF decryption

The current tool is designed to perform supported decryption in your browser rather than intentionally sending PDF contents to a SoloBizKit conversion server. The page and required libraries still load from the internet, so browser-based processing should not be described as fully offline.

Unlock PDF FAQ

Can I remove a PDF password for free?

Yes, when you know the correct password and the PDF uses a supported encryption type. No SoloBizKit account is required.

Can this unlock a PDF without the password?

No. A valid user or owner password is required.

Which encrypted PDFs are supported?

The current tool supports AES-256 and RC4 encrypted PDFs. AES-128 is not supported by the current version.

Does unlocking change my original PDF?

No. A new decrypted PDF is created for download and your original file remains unchanged.

Can I protect the PDF again later?

Yes. Use Protect PDF to create a new password-protected copy.

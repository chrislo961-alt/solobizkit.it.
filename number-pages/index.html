Add page numbers to a PDF document

Use the free SoloBizKit PDF page numbering tool for reports, proposals, contracts, manuals, assignments and other documents that are easier to navigate when every page has a visible number.

Choose where PDF page numbers appear

Place page numbers at the bottom center, bottom right, top center or top right of the page. The tool uses a simple standard font so numbering remains clear without unnecessarily changing the rest of the document.

Start PDF numbering from any number

Not every document should begin at page 1. Set a custom starting number when your PDF is part of a larger report, follows a cover section or continues numbering from another document.

Add page numbers to reports, proposals and manuals

Page numbers make long documents easier to reference in meetings, reviews and printed copies. They can be especially helpful for client proposals, policy documents, manuals, academic work and multi-page reports.

Does numbering change the original PDF?

No. The tool creates and downloads a new numbered PDF. Your original file remains unchanged on your device.

Free PDF page numbering without an account

The current Number PDF Pages tool is free to use and does not require a SoloBizKit account. Processing is designed to happen in your browser. Password-protected or damaged PDFs may need to be unlocked or repaired first.

PDF page numbering FAQ

Can I number a PDF online for free?

Yes. Choose a PDF, select the number position and starting number, then create the numbered copy without creating a SoloBizKit account.

Can numbering start at 5 or 10 instead of 1?

Yes. Enter any positive starting number and the sequence continues from there.

Can I put page numbers at the top?

Yes. The current tool supports top center and top right, as well as bottom center and bottom right.

Can I number only selected pages?

The current version numbers every page. If only part of a document should be numbered separately, use Split PDF first and then number the extracted document.
